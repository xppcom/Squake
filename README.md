[Squake](http://www.minecraftforum.net/forums/mapping-and-modding/minecraft-mods/2181015-squake-quake-style-movement-for-minecraft)
======

Minecraft mod that adds Quake-style, [Fortress Forever](http://www.fortress-forever.com) inspired movement to the game. Modified version with a speed cap at 200km/h
